# REVIEW

Plantilla para solicitar cambios y actualizaciones al proyecto.

Este fichero es un documento de mando: se rellena con la solicitud, se ejecutan los cambios y se vacía para la siguiente iteración. Obedece las reglas de `AGENTS.md` y las directrices de `PRODUCT.md`.

---

## Formato de solicitud

Describir los cambios deseados con la mayor claridad posible. Incluir:

- **Qué cambiar**: archivos, componentes o secciones afectadas.
- **Cómo debe quedar**: resultado esperado, capturas de referencia si aplica.
- **Restricciones**: cualquier condición adicional que no esté en `AGENTS.md`.
